# 好好生活 · 本地待办工作台

> 一个为安卓用户（兼容华为/荣耀系统）打造的、纯本地、不联网、不注册的轻量级待办 App。

## 🎯 项目背景

市面上多数待办工具都需要注册账号、上传数据到云端。对于只需要"安静记点事情"的用户来说，这些流程是负担，数据隐私也是隐患。

这个 App 的定位是：**打开就能用，数据只在你手机里，不联网、不上传、不绑定任何账号。**

## 👤 目标用户

- 不想注册账号、不想被推荐算法打扰的用户
- 对数据隐私敏感、希望记录只存在本地的用户
- 安卓/荣耀/鸿蒙系统用户（兼容性是核心考量）

## 🛠️ 技术栈

- **前端**：原生 HTML / CSS / JavaScript
- **本地存储**：localStorage
- **打包工具**：HBuilderX（5+App → 云打包 APK）
- **AI 能力**：智谱 GLM-4-Flash（免费大模型 API）
- **第三方库**：SortableJS（拖拽排序）

## ✨ 功能列表

- 每日待办清单，自动排序 + 手动拖拽排序
- 待办分类（工作/学习/生活/其他）
- 星标重点事项
- 日历视图 + 历史记录回看
- 历史待办与碎碎念关键词搜索
- 每日心情记录
- 每日碎碎念
- 加密导出 / 导入（换机备份）
- AI 月度总结（基于本地数据生成）
- 明文 Markdown 导出

## 🔥 核心难点与解决方案

### 难点 1：华为/荣耀系统对本地文件读写的沙盒限制

**问题描述**：导出的备份文件保存在 `Android/data/<包名>/files/` 目录下，但华为/荣耀的系统文件管理器**强制隐藏**该目录，用户无法找到文件，导致换机备份功能形同虚设。

**排查过程**：
- 尝试 1：使用自定义后缀 `.workbench` → 系统无法识别，直接关联到"相机"打开（失败）
- 尝试 2：使用 `plus.share.sendWithSystem` 分享文件到微信 → 基座环境缺少 Share 模块（失败）
- 尝试 3：使用 Android MediaStore API 写入公共下载目录 → 基座环境权限不足（失败）
- 尝试 4：调用系统文件管理器跳转 → 荣耀能跳转但看不到文件（系统级隐藏）

**最终方案**：
- 导出文件改用 `.txt` 后缀，让系统识别为普通文本
- 在应用内弹窗展示**完整文件路径**，并提供"一键复制路径"按钮
- 用户复制路径后，可自行前往文件管理器查找

**结果**：绕过了系统级限制，换机备份功能在华为、荣耀、小米等设备上均可使用。此功能虽还不方便，但还存在后续优化空间

### 难点 2：移动端拖拽排序与页面滚动手势冲突

**问题描述**：手机上用户想上下滑动页面时，经常误触发拖拽排序，导致体验混乱。

**解决方案**：
- 引入 SortableJS，配置 `delay: 1000`（按住 1 秒才启动拖拽）
- 为每条待办右侧添加独立的"拖拽把手 ☰"，只有按住把手才触发拖拽
- 页面的上下滑动完全不受影响

### 难点 3：AI 接入与本地数据隐私的平衡

**问题描述**：希望引入 AI 生成月度总结，但不能上传用户隐私数据到云端。

**解决方案**：
- 用户主动点击"生成本月总结"时，才**一次性**将当月数据发送给 AI API
- 未配置 API Key 时，自动降级为本地模拟版本，保证功能可用
- 全流程不涉及用户身份信息，只发送待办事项文本

## 📱 安装使用（给非技术用户）

**如果你是普通用户，只想安装到手机上使用：**

1. 点击本页面右侧的 **Releases**（或点击 [这里](https://github.com/Echo-Henry/MyWork/releases/tag/v1.5))。
2. 找到最新的 `好好生活 v1.5` 版本。
3. 在 `Assets` 里点击下载 `MyWork.for.android_V1.5.apk` 文件。
4. 把 APK 传到你的华为/荣耀手机上安装即可（首次安装需允许“未知来源应用”）。

> ⚠️ 首次安装如果提示“安全警告”，请选择“继续安装”。
> 这个 App 不联网、不上传数据，请放心使用。
